# AI 协作文档

这组文档用于让 AI 在修改 Grove 前先建立正确上下文，避免根据通用 Java、DDD 或旧计划模板猜测项目结构。

## 推荐读取顺序

1. 仓库根目录 [AGENTS.md](../../AGENTS.md)
2. [项目上下文](project-context.md)
3. [项目架构](../architecture.md)
4. [命令参考](../commands.md)
5. 任务相关的 canonical guide
6. 需要追溯设计原因时再读 `docs/plans/`

## AI 的基本原则

- 先读当前代码，再判断文档是否过时。
- 先定位真实入口、状态真相源、调用链和关闭路径。
- 先做最小完整改动，不为单一实现预留抽象。
- 复杂业务可以使用面向对象和设计模式，但必须有真实变化点和稳定边界。
- 不把模型文本、前端显示状态或缓存当作安全真相源。
- 完成时必须提供当前命令的验证证据，并区分本地完成与外部依赖未就绪。
